# Help Desk Ticket Tracker

A C# console application for managing basic IT support tickets. It allows users to create, view, search, and update tickets while saving the information between sessions.

## Features

- Create new support tickets
- Automatically assign ticket IDs
- View all existing tickets
- Search for tickets by ID
- Update ticket statuses
- Validate user input
- Save and load tickets using JSON

## Technologies Used

- C#
- .NET
- System.Text.Json
- Visual Studio 2022
- Git and GitHub

## How to Run the Project

1. Clone or download this repository.
2. Open `HelpDeskTicketTracker.sln` in Visual Studio.
3. Build the solution.
4. Press `Ctrl + F5` to run the application.
